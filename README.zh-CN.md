> 一张表：所有AI订阅按¥10理论Token排行。按量计费精确，按次计费亮公式估算。

## 运行
1. `plans.json` 存价格+额度+公式。
2. `index.html` 按¥10 Token排序，无构建。
3. 直接打开`index.html`或开Pages。

## 收录
| 文件 | 说明 |
|---|---|
| `plans.json` | 3个种子套餐，带公式+来源 |
| `index.html` | 静态排行，仅fetch+排序 |

## 贡献
